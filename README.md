# 23-skills

A growing collection of my reusable AI agent skills. The name is a nod to my favorite number, not a target for how many skills this repo should contain.

## Structure

Each skill will live in its own folder under `skills/`:

```text
skills/
  skill-name/
    SKILL.md
    references/   # optional
    scripts/      # optional
```

I'll add skills as I develop and test them. There are no published skills yet.
